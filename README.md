# 战国风云（JavaScript + Three.js）

一个用纯 JavaScript + HTML + CSS 编写的《全面战争》式战略游戏原型，主题为中国战国时期七国争霸，
用 [Three.js](https://threejs.org/) 渲染 3D 地形地图。

## 目录结构

```
index.html          页面入口
css/style.css       样式
js/
  gameData.js       游戏数据与规则（阵营、城市、军队、外交、回合结算、等级/人口/粮食系统）
  noise.js          简单的程序化地形噪声函数
  main.js           启动入口
  world3d/          Three.js 3D 地形/河流/树木/城池/将领模型/相机/寻路
  ui/               各界面（选阵营、顶部栏、城市面板、军队面板、小地图、外交面板、战役地图）
```

## 如何运行

浏览器出于安全限制，不允许直接用 `file://` 双击打开 `index.html` 加载 ES 模块，
需要通过一个本地静态服务器访问。在项目根目录下任选一种方式执行：

```powershell
# 方式一：Node.js（你的电脑上已安装 Node 22）
npx serve .

# 方式二：Python
python -m http.server 8080
```

然后在浏览器打开命令行提示的地址（如 `http://localhost:3000` 或 `http://localhost:8080`）。

也可以在 VS Code 里安装 "Live Server" 插件，右键 `index.html` -> `Open with Live Server`。

> 首次加载需要联网，因为 Three.js 是通过 `index.html` 里的 `importmap` 从 CDN
> (`unpkg.com`) 加载的，没有打包到本地文件里。

## 操作说明

- 打开页面先选择一个阵营，进入战役地图。
- **鼠标滚轮**缩放视角，**WASD / 方向键** 平移镜头。
- 战役地图约为原来的十倍面积，加入更多中国战国区域城镇、关隘与资源点；资源点由控制方每回合获得金币。
- 点击城市/军队图标，右侧会弹出对应面板；点击己方军队后地图会显示城市和资源点的行军花费，点击可达地点即可下令。每次移动约消耗每 55 点地图距离对应的行动点；骑兵行动点较多，混编军团按最慢兵种计算。攻城额外消耗 2 点，未使用的行动点可用于多次行军，并在新回合恢复。
- 点击目标城后会生成避开河流、偏好平缓地形的虚线路线；将领沿路线实时行军，行动点不足时会在下回合沿同一路线继续。
- 每支军团都有一名持阵营旗和剑的 3D 将领；城中驻军模型按兵种显示盔甲、长戟/弩和战马等装备。
- 军队面板展示将领、兵种卡牌与战役小地图。普通将领使用随机姓名；驻扎在己方城池且未行军的军队，每回合按缺员兵力恢复 6%，将领可提供额外恢复率。境外驻军和行军军队不会恢复。
- 顶部「外交」按钮可以结盟、宣战、求和；「结束回合」结算金币收入并进入下一回合。
